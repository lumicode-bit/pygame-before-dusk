暮色之前 · Before Dusk
========================================

【怎么玩】
双击 暮色之前.exe 即可，不需要安装，也不用带别的文件。
第一次启动约 3~6 秒（单文件 exe 要先解包），之后会快一些。

【操作】
  移动 ............ WASD 或 方向键
  跳跃 / 二段跳 ... 空格
  冲刺（无敌帧）... Shift
  射箭（弓箭手）... 鼠标左键（有准星）
  挥剑（盾卫）..... J
  格挡（盾卫）..... K 或 鼠标右键
  开补给箱 ........ E
  换人 ............ Tab（单人模式）
  同伴指令 ........ F（跟随 / 守点 / 集火）
  聊天 ............ Enter
  帮助 / 暂停 ..... F1 / Esc

【双人闸门】
熔炉长廊中段有一道铁闸门，附近有两块机关。只踩一块是打不开的：
  1. 你站上一块（会亮）
  2. 按 F 把同伴切成「守点」，它会去站另一块
  3. 两块同时亮 0.45 秒，闸门升起
联机时两人各踩一块即可。

【难度 / 教学 / 界面缩放】
选角页可选难度：简单 / 标准 / 困难（影响怪物血量与伤害）。
首次单机开局有 5 步教学（移动→跳跃→冲刺→攻击→格挡），按 F12 跳过。
设置 → 画面 → 界面缩放可放大文字（90%~140%）。

【共鸣门（一守一取）】
瞭望塔二层有一道门：一人站守门符文（门开），另一人进隔间取补给打精英。
单机：站上符文后按 F 切「守点」，AI 会自动替你守门。
联机：一人守符文，一人进隔间，然后互换。

【局域网自动发现】
创建房间会自动向局域网广播；「加入房间」页会列出发现的房间，点击即可加入。
跨网络仍需 ngrok 或端口映射（Steam/EOS 邀请需接入其 SDK，暂未实现）。

【藤蔓滑索 / 上层路线】
地图有上下两层：森林断桥和岩浆上方捷径，用藤蔓滑索连起来。
  靠近藤蔓 → 按 空格 或 E 抓住
  挂住后 ← → 沿索滑动（按住方向键就行，不会掉）
  松手：松开跳键后再按一次跳 / 按 E 或 S / 朝端点方向继续推
  按住跳键不放不会被甩下来（抓取和松手是"重新按下"判定）
两条上层路线上各有一个补给箱，走上层更快也更肥。

【三幕材质】
森林是草地，岩壁到深坑是焦土/玄武岩，熔炉长廊是铁板——三段地面材质完全不同，
靠地面颜色就能判断自己到哪儿了。

【挑战与记录】
选角页下方可以勾选挑战词条（可多选，倍率相乘）：
  玻璃大炮：受到伤害 ×1.5，得分 ×1.5
  精英狩猎：第二波地面怪全变精英，得分 ×1.3
  断补给：补给箱失效，得分 ×1.2
通关后结算页会显示本次得分和历史最佳（最快用时 / 最高击杀 / 最佳评级 / 最高分）。

【改键 / 手柄】
设置 → 操作：点一下任意一行的按键，然后按你想用的键即可（Esc 取消）。
「恢复默认键位」可以一键还原。

接上手柄会自动识别：
  左摇杆移动 · A 跳 · B 冲刺 · X 射箭 · Y 格挡 · LB 挥剑 · RB 交互
  右摇杆控制弓箭手瞄准方向

【不适可以关】
设置里的「震屏强度」「受击闪烁」都能拉低或拉到 0，只影响画面，不影响伤害判定。

【重要提示】
1) 如果画面在动但角色不动：用鼠标点一下游戏窗口。
   Windows 不会自动把键盘焦点交给新窗口，点一次就好。
2) 杀毒软件/Windows Defender 可能提示"未知发布者"或误报。
   这是 PyInstaller 单文件打包的常见误报（没有购买代码签名证书），
   选择"更多信息 → 仍要运行"即可。
3) 设置保存在 exe 同目录的 settings.json，删掉就恢复默认。
   如果 exe 放在没有写权限的目录（如 Program Files），
   设置会自动存到 C://Users//你的用户名//.before_dusk_settings.json

【新敌人】
· 熔岩术士（紫色斗篷、漂浮）：会朝你扔火球。
  弓箭手可以用箭把火球打爆；盾卫举盾（K）能直接挡下。别站着不动。
· 精英兽（脚下紫环、头顶紫钻）：比普通怪更肉更疼，优先集火。

【Boss · 熔炉守卫】
走到终点祭坛会唤醒守卫。它蓄力时会全身发红，随后沿直线冲锋：
看到红光就按 Shift 冲刺躲开，冲完它会僵直两秒，那是输出窗口。
守卫有三个阶段：
  一阶段：红光蓄力后直线冲锋 —— 看到红光就冲刺躲开。
  二阶段（66%）：会跳起来砸地，落地放出贴地冲击波 —— 跳起来躲。
  三阶段（33%）：召唤两名术士 —— 弓箭手清场，盾卫顶住守卫。
冲锋不能一直举盾硬吃：举盾 0.16 秒内被撞才算"完美格挡"，守卫会硬直；
一直举着会被撞飞并掉血。
击败它，传送门才会开启。

【玩法要点】
· 两人共用一条命：任一角色阵亡，两人一起在最近检查点复活（回 60% 血）。
· 弓箭手能射碎岩石墙、打下飞行怪；盾卫能格挡减伤、踩压力机关生成跳板。
· 单人模式另一名角色由 AI 托管，卡住时会自动"归队"到你身边。
· 目标是清掉两波怪 → 击败熔炉守卫 → 两人一起走进终点祭坛的传送门。

祝你玩得开心。
